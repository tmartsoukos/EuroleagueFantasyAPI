# Ακριβείς εκδόσεις όλων των πακέτων (constraints) για αναπαραγώγιμη εγκατάσταση.
#
# Χρήση (CI και Render):
#   pip install -r requirements.txt -c constraints.txt        # εξαρτήσεις εκτέλεσης (Render)
#   pip install -r requirements-dev.txt -c constraints.txt    # εξαρτήσεις ανάπτυξης και tests (CI)
# Το αρχείο ΔΕΝ προσθέτει πακέτα: το pip το χρησιμοποιεί μόνο για να διαλέξει συγκεκριμένες εκδόσεις
# από όσα ζητούν τα requirements*.txt. Έτσι οι εκδόσεις των xgboost, numpy, scipy, scikit-learn,
# pandas, pyarrow, joblib κ.λπ. ταυτίζονται με αυτές της εκπαίδευσης του committed μοντέλου
# (models/model.joblib, βλ. library_versions στο models/metrics.json) και το quality gate δίνει
# τα ίδια αποτελέσματα στο CI, στο Render και στο laptop.
#
# Πηγή: `pip freeze --exclude-editable` στο περιβάλλον όπου εκπαιδεύτηκε το μοντέλο (Windows 11,
# Python 3.13.2, 2026-10-04), χωρίς το ίδιο το πακέτο elfantasy (editable) και χωρίς το colorama,
# που εγκαθίσταται μόνο στα Windows. Οι εκδόσεις ελέγχθηκαν ότι υπάρχουν ως wheels για Linux με
# Python 3.12 (docs/DEPLOY.md, ενότητα «Αναπαραγώγιμες εκδόσεις»): μια καθαρή εγκατάσταση σε Ubuntu
# 24.04 με Python 3.12 έδωσε ακριβώς τις ίδιες εκδόσεις, συν το nvidia-nccl-cu13 παρακάτω.
#
# Η γραμμή με `; sys_platform == "linux"` ισχύει μόνο σε Linux: το nvidia-nccl-cu13 είναι εξάρτηση
# του xgboost που εγκαθίσταται μόνο εκεί (δεν υπάρχει στο περιβάλλον Windows της εκπαίδευσης). Η
# έκδοσή του προέρχεται από την παραπάνω εγκατάσταση σε Linux και καρφώνεται για αναπαραγωγιμότητα.
#
# Πώς ξαναπαράγεται (από τη ρίζα του repo):
#   1. Καθαρό venv: python -m venv .venv-lock
#   2. .venv-lock/Scripts/python.exe -m pip install -r requirements-dev.txt
#   3. .venv-lock/Scripts/python.exe -m pip freeze --exclude-editable   (αφαίρεσε το colorama)
#   4. Αντικατέστησε τις γραμμές εκδόσεων παρακάτω και κράτησε αυτό το σχόλιο.
#   5. Έλεγξε σε Linux (π.χ. WSL ή το CI) με Python 3.12: pip install -r requirements-dev.txt -c
#      constraints.txt && pip freeze, και πρόσθεσε στο τέλος τα πακέτα που εμφανίζονται μόνο εκεί.
# Αν αλλάξει η έκδοση των numpy, scipy, scikit-learn, pandas ή xgboost, ξαναεκπαίδευσε το μοντέλο
# (python -m elfantasy.model.train) και κάνε commit μαζί το νέο constraints.txt και το νέο artifact.
# Ένα test (tests/unit/test_ci_config.py) ελέγχει ότι οι εκδόσεις εδώ ταυτίζονται με του μοντέλου.
